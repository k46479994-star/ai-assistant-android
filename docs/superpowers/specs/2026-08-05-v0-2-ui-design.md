# AI 비서 v0.2 UI 설계

## 목표
기존 기능 테스트형 채팅 화면을 실제 앱처럼 보이는 단일 액티비티 MVP로 개선한다.

## 범위
- 상단 인사 및 온라인 상태
- 홈/채팅/일정/할 일/설정 하단 메뉴
- 홈 요약 카드
- 채팅 입력창과 말풍선
- 일정 화면의 Google 캘린더 일정 추가 진입
- 할 일 데모 목록
- 설정 화면의 앱 정보

## 구현 방식
현재 의존성을 최소화하기 위해 XML/Compose 대신 Kotlin 코드 기반 View UI를 유지한다. `MainActivity`가 화면 컨테이너와 하단 내비게이션을 관리하고 각 탭은 독립된 View 생성 함수로 분리한다.

## 데이터 흐름
탭 선택 → 콘텐츠 컨테이너 교체 → 화면별 로컬 데모 데이터 표시. 일정 추가는 `CalendarContract.ACTION_INSERT` 인텐트로 Google 캘린더 앱에 전달한다.

## 오류 처리
캘린더 앱이 없으면 토스트로 안내한다. 빈 채팅 메시지는 전송하지 않는다.

## 검증
GitHub Actions에서 `assembleDebug` 성공과 APK 아티팩트 업로드를 확인한다.
